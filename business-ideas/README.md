# Open-Source White-Label Business Catalog

3755 verified open-source projects across 444 categories that can be self-hosted, rebranded and turned into a business. Every repo was confirmed on GitHub on 2026-11-04 via the search API, with `git ls-remote` as a fallback for repos search misses (stars, license and archive status are as of then; ? = not available).

**License key** (what it means for white-labeling):
🟢 permissive (MIT/Apache/BSD), rebrand and sell freely, keep notices · 🟡 weak copyleft (MPL/LGPL), share changes to *their* files · 🟠 GPL, fine for hosted SaaS, but distributed apps must ship source · 🔴 AGPL, hosted users must be offered your modified source · ⚪ other: NOASSERTION means GitHub couldn't auto-detect it (often dual, custom or source-available), NONE means no license file, so read the license before you build a business on it.

📦 = repo archived (fork it or pick another). Not legal advice; trademarks/logos are never licensed, so always rebrand.

## How to use this

1. Pick a category, then pick a 🟢/🟡 project for the most freedom (or 🟠/🔴 if you're happy hosting it as a service and publishing your changes).
2. Pick a niche: the generic version usually exists already, the money is in "X for dentists", "X for churches", "X in Portuguese".
3. Rebrand (name, logo, domain, colors), add onboarding, billing and support. That's the product.
4. Business models that work repeatedly: managed hosting · white-label reseller for agencies · vertical SaaS · setup + support retainers · mobile app built on the open-source backend.
